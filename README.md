# hoppscotch-railway

Wrapper image for the Railway template "Hoppscotch": `hoppscotch/hoppscotch:2026.10.1` (MIT) with a boot script that
applies migrations, closes onboarding, seeds an administrator and an infra token from `HOPPSCOTCH_INFRA_TOKEN`, and moves
the web app onto Railway's `PORT`. Source of the template: github.com/bon5co/railwaytemplate2.
